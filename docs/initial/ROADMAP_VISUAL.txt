┃ 🏗️  ARQUITECTURA EN 60 SEGUNDOS                                                ┃
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫
┃                                                                                 ┃
┃  ┌─ NETWORK THREAD ────────────────────────────────────────┐                  ┃
┃  │ ├─ Descargar M3U8 (libcurl + TLS)                       │                  ┃
┃  │ ├─ Parsear canales                                      │                  ┃
┃  │ └─ Descargar segmentos TS (streaming)                   │                  ┃
┃  │    → Enqueue a NetworkBuffer (50 MB)                   │                  ┃
┃  └──────────────────────────────────────────────────────────┘                  ┃
┃           ↓ CircularBuffer + Condition Variable                                ┃
┃  ┌─ DECODER THREAD ─────────────────────────────────────────┐                 ┃
┃  │ ├─ Dequeue TS bytes de NetworkBuffer                   │                 ┃
┃  │ ├─ FFmpeg demux + decode                               │                 ┃
┃  │ │  ├─ H.264 video → YUV frames                         │                 ┃
┃  │ │  └─ AAC audio → PCM samples                          │                 ┃
┃  │ └─ Enqueue VideoFrames + AudioFrames                   │                 ┃
┃  └──────────────────────────────────────────────────────────┘                 ┃
┃           ↓ CircularBuffer (Video: 300MB, Audio: 10MB)                        ┃
┃  ┌─ RENDER THREAD (Main) ───────────────────────────────────┐                 ┃
┃  │ ├─ Dequeue VideoFrame, render con OpenGL               │                 ┃
┃  │ ├─ Dequeue AudioFrame, play con SDL2 audio             │                 ┃
┃  │ ├─ Mantener 60 FPS (16.67ms per frame)                 │                 ┃
┃  │ └─ A/V synchronization (PTS tracking)                  │                 ┃
┃  └──────────────────────────────────────────────────────────┘                 ┃
┃           ↓ GUI (ImGui) - Observa cambios de estado                           ┃
┃  ┌─ GUI LAYER (ImGui) ──────────────────────────────────────┐                 ┃
┃  │ ├─ Channel list (filtrable)                            │                 ┃
┃  │ ├─ Play/Pause/Stop botones                             │                 ┃
┃  │ ├─ Video canvas (OpenGL texture)                       │                 ┃
┃  │ └─ Stats panel (bitrate %, FPS, buffer %)              │                 ┃
┃  └──────────────────────────────────────────────────────────┘                 ┃
┃                                                                                 ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
